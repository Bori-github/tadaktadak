# Android 알림 채널

Android 8.0(API 26)부터 쓰는 알림 채널의 개념과 동작

## 채널

- 채널은 앱이 보내는 알림의 종류다. 알림이 울리는 방식은 알림 단위가 아니라 채널 단위로 정한다
- 알림은 반드시 채널 하나에 속한다. 채널을 지정하지 않은 알림은 표시되지 않는다
- `expo-notifications`는 채널을 지정하지 않은 알림을 자체 기본 채널 `expo_notifications_fallback_notification_channel`(이름 `Miscellaneous`)로 보낸다

## 채널에 붙는 설정

| 설정   | 내용                                             |
| ------ | ------------------------------------------------ |
| 중요도 | 화면 위 팝업 여부. `HIGH` 이상이면 팝업으로 표시 |
| 소리   | 알림음 재생 여부와 소리 파일                     |
| 진동   | 진동 여부와 패턴                                 |

- 알림은 속한 채널의 설정대로 울린다

## 생성 이후

- 앱은 채널을 만들 때 초기값만 정한다. 생성 후에는 이름과 설명만 바꿀 수 있고 중요도·소리·진동은 바꿀 수 없다
- 설정이 다른 알림이 필요하면 새 채널 ID로 채널을 만든다

## 사용자 설정

- 시스템 설정의 앱 알림 화면에 채널이 이름과 함께 나열된다 (삼성: 설정 › 애플리케이션 › 앱 › 알림)
- 사용자는 채널마다 알림 끄기, 소리·진동을 바꿀 수 있다. 사용자가 바꾼 값이 앱의 초기값보다 우선한다

## iOS와 차이

| 항목            | Android             | iOS                     |
| --------------- | ------------------- | ----------------------- |
| 울리는 방식     | 채널 단위           | 알림 단위               |
| 소리 지정       | 채널 설정           | 알림의 `content.sound`  |
| 알림별로 다르게 | 보낼 때 채널을 고름 | 알림마다 값을 직접 지정 |

- 알림마다 진동 여부를 다르게 하려면 설정이 다른 채널을 미리 만들어 두고, 알림을 보낼 때 채널을 선택한다
