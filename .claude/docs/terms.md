# 용어 정리

한 개념에 한 표기를 쓴다. 문서, 주석, 테스트 이름, 커밋, PR에 모두 적용한다.

## 타이머(timer)

- `mm:ss` 형태로 나타내는 시간 값
- 타이머 모드(timer mode): 집중, 휴식으로 구성
  - 집중: focus
  - 휴식: rest
- 타이머 단계(timer phase): 타이머 대기, 일시정지, 진행, 완료로 구성
  - 대기: ready
  - 일시정지: paused
  - 진행: running
  - 완료: completed
- 타이머 설정(timer settings): 집중/휴식 타이머를 설정
  - 대기 상태에서 타이머 숫자 터치 -> 해당 타이머 설정 활성화 -> 타이머 시간 변경의 흐름으로 타이머를 설정
- 타이머 조작 버튼(button)
  - 재생/일시정지
  - 정지

## 세션(session)

- 타이머의 생명 주기
- 각 타이머는 대기, 일시정지, 진행, 완료의 생명 주기를 가짐

## 시계 요소

- 시계판: dial
- 눈금: tick
- 5분 단위 눈금: major tick
- 눈금 라벨: numeral
- 타이머 남은 시간 표시(호): arc
  - 손잡이: thumb

## 그외 요소

- 기준 표식: marker
- 장작: log
- 모닥불: bonfire
- 불티: ember
- 빛 번짐: bloom
