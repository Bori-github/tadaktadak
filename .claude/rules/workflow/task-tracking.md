# 작업 추적

새 작업은 Notion에 먼저 등록한 뒤 저장소에서 브랜치를 생성해 시작한다. WBS에서 브랜치마다 연결된 기능 명세와 배포 버전을 함께 확인할 수 있다.

## 작업 시작 순서

1. **기능 명세 작성**: 기능을 추가하거나 동작을 변경하는 작업이면 기능 명세서에 명세를 먼저 작성한다. 기능 명세 템플릿의 속성을 모두 입력하고 사용자 확인을 받으면 2단계로 진행한다. 문서, 설정, 테스트 작업과 급한 버그 수정은 이 단계를 생략한다. 버그 수정이 동작을 변경하면 머지 후 명세를 수정한다
2. **WBS 행 생성**: 브랜치 하나에 행 하나를 생성한다. 기능 작업이면 행의 `기능 명세` 속성에 1번 명세를 연결한다. 생성한 행을 다시 조회해 TASK ID를 확인한다
3. **브랜치 생성**: 이름은 `<type>/<TASK ID 번호>-<설명>` 형식으로 지정한다. 예를 들어 TASK-99 문서 작업은 `docs/99-plan-cleanup`으로 지정한다

착수 요청에 해당하는 WBS 행이 없으면 행 생성을 먼저 제안하고, 행이 생성되면 착수한다. 진행 중인 브랜치에서 함께 처리하는 작업은 새 행을 생성하지 않고 그 브랜치의 행 제목에 추가한다.

## WBS 행 갱신

- PR을 생성하면 WBS 행의 `PR` 속성에 PR 주소를 입력한다
- 진행현황(작업 중, 작업 완료, 배포 완료)을 변경하는 시점은 WBS 페이지 위쪽 작성 규칙을 따른다
